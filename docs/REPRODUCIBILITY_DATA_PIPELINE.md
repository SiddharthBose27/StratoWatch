## Overall classification

The multi-site raw-to-final data pipeline is **PARTIALLY REPRODUCIBLE**. The scripted alignment/window/split stages are inspectable and deterministic, but final feature engineering and scaling are notebook-dependent and not hash-linked to the current raw inputs.

The single-site pipeline is **NOT REPRODUCIBLE** end-to-end from the current artifact set because feature metadata does not match sequence width. The residual scaler itself is loadable through Joblib, with a scikit-learn version warning.

The final multi-site model/evaluation path is **PARTIALLY REPRODUCIBLE** from frozen artifacts: the final NPZ, masks, scalers, adjacency, coordinates, and checkpoints are present and loadable, but the original raw-to-final derivation and exact environment are not proven.

## Safe conclusion

Phase 2 establishes lineage and current artifact contracts. It does not establish byte-identical regeneration, and no regeneration was attempted.
